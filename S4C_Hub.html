How S4C Tools works

Everything runs on this PC. Only the GitHub update check goes online.

Pick a tool and press Run

Choose a tool on the left and press Run (or Enter). S4C Tools checks GitHub for that one tool, then opens it in its own window, exactly as before. Pick your files in that window.

Updates from GitHub

Only the tool you choose is checked. The bar at the top says Newest version, Updated or Not connected. If GitHub can't be reached, the copy on this PC is used and the tool still runs.

Your files are safe

Each tool saves a new copy next to your file (Fixed, Remediated, AltText, Links). IMBK Tool works on the file itself and keeps a backup named _BEFORE_IMBKfix.

Daily report

Every saved file is noted with its slide or page count. Open Today's work and press Download report. A chapter run through several tools counts once.

Keep the S4C Tools window open

This page runs from the small S4C Tools window. Closing that window closes S4C Tools. Double-click S4C Tools.cmd to open it again.

Something not working?

Use S4C Tools - classic menu.cmd in the same folder; it runs the same tools from a text menu. Send a screenshot of any red message to Hari.

S4C Tools was closed

The S4C Tools window was closed. Double-click S4C Tools.cmd to open it again.
